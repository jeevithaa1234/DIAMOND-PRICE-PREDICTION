# 💎 Diamond Price Prediction using Machine Learning

A Machine Learning-powered web application that predicts the price of a diamond based on its physical and quality characteristics. The application is built using **Python, Flask, Scikit-learn, HTML, CSS, JavaScript, and SQLite**, providing users with fast and accurate price predictions through an intuitive web interface.

---

## 📖 Project Overview

The Diamond Price Prediction system helps estimate the market price of diamonds using machine learning algorithms. Users enter details such as carat, cut, color, clarity, depth, table, and dimensions, and the trained model predicts the estimated price instantly.

The project demonstrates an end-to-end machine learning workflow, from data preprocessing and model training to deployment in a Flask web application.
